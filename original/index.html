🎮 Jones — Original Game Launcher

Run your own copy of the original 1991 game in a phone-friendly browser player. This page is an emulator launcher, not a recreated game.

Choose the prepared .zip or .jsdos game bundle from Files to begin. Updated launcher: reads game locally and starts automatically.

To hide Safari’s tabs: in Safari, tap Share → Add to Home Screen → Add, then open Jones from the new Home Screen icon. This is the closest iPhone/iPad equivalent to true fullscreen.

Your selected game stays on your device. The game is not uploaded to this website. Internet access is required to load the js-dos emulator.

How to use

1. Download the prepared game bundle (prefer the .zip version on iPhone) and save it to Files. 2. Tap “Choose my game bundle” above and select it. If it is still greyed out, open the Files app and check the download location. Use the emulator’s on-screen mouse or touch controls; select fullscreen for more room.

Not a ROM download: the original Sierra game files and artwork are not distributed here. For another route, ScummVM supports the game using your own game data.
