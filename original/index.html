How to use

1. Supply a legally obtained DOS copy of Jones in the Fast Lane. 2. Convert your DOS game folder into a .jsdos bundle using the js-dos Game Studio. 3. Tap “Choose my game bundle” above. Use the emulator’s on-screen mouse or touch controls; select fullscreen for more room.

Not a ROM download: the original Sierra game files and artwork are not distributed here. For another route, ScummVM supports the game using your own game data.
